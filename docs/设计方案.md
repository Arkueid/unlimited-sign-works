# 设计方案

## 模块
### core
管理顶点数据和纹理索引。

mesh: 基础几何体
part: 组成标识牌的部件，管理 mesh，及其 坐标变换
pole: 标识牌，管理 part

### app
OpenGL 绘制和界面

## 复用
使用引用计数，按需加载，动态销毁。

按需加载：仅在第一次创建时加载，之后复用。
动态销毁：当引用计数为 0 时销毁。

### Mesh 复用
参数相同的 mesh 可以复用，减少内存占用。

### vertex buffer 复用
顶点数据相同的 buffer 可以复用，减少内存占用。

### 纹理复用
纹理相同的图片可以复用，减少内存占用。


## 标识牌参数化
PoleJsonSerializer: 将标识牌参数导出为 json 文件，或从 json 文件生成 pole。


## 发布标识牌模型

使用相对纹理索引，并将纹理和标识牌json文件一同导出。
```
Pole168
|- pole.json
|- textures
|   |- pole.png
|   |- pole_detail.png
|   |- pole_detail2.png
```
