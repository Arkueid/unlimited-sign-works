# 标识牌面板模板

## 配置文件样例

类型：
* 1 => 汉字
* 2 => 拼音
* 3 => 英文
* 4 => 字母+数字
* 5 => 单位

颜色：
* W => 白色
* G => 绿色
* B => 黑色
* Y => 黄色
* R => 红色
* Z => 棕色

格式：

```cfg
名称 大小
类型 前景色 背景色 数量 宽度*高度
x y // x，y 的原点是左下角
```

示例：

```cfg
D4 4500*4000
1 B Y 3 100*100
1950 3520
2200 3520
2450 3520
4 W G 3 300*500
1755 2800
2100 2800
2445 2800
1 W G 2 600*600
400  1800
1300 1800
2 W G 1 1500*300
400  1300
1 W G 2 600*600
2600 1800
3500 1800
2 W G 1 1500*300
2600 1300
```

## 绘制流程
模板文字绘制顺序：先绘制背景填充矩形，在绘制文字
